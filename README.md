# Лабораторная работа №1. Разработка Технического задания

## 1 Введение

Настоящее техническое задание распространяется на разработку приложения, посвященного колористике. Предполагается, что данное приложение будет использоваться начинающими художниками и дизайнерами.

Приложение предназначено для изучения колористики и получения навыков работы с цветом. Включает в себя три функциональных области: "цветовой круг", "рисование" и "цветовая классификация" с интуитивно понятным интерфейсом для смешивания, применения различных оттенков, а также проверки полученных знаний. Каждая функциональная область нацелена на развитие навыков в колористике и углубление понимания цветовой теории.

Актуальность приложения обусловлена важностью цвета в изобразительном искусстве и визуальных коммуникациях, что способствует улучшению художественных способностей пользователей и позволяет освоить основы колористики.

## 2 Основание для разработки

Задание на проектирование в рамках изучения МДК 02.01 «Технология разработки программного обеспечения» по специальности 09.02.07 «Информационные системы и программирование», факультет СПО №12 СПБГУАП.

## 3 Назначение разработки

Создание обучающей программы для начинающих художников и дизайнеров на тему "Теория цвета".

Описание функциональности продукта:

- Возможности для смешивания различных оттенков.
- Возможность создания изображений с использованием выбранных оттенков.
- Поддержка проверки знаний теории цвета через тесты и викторины.

## 4 Требования к программе или программному изделию

### 4.1 Требования к функциональным характеристикам

Программа должна обеспечивать возможность выполнения следующих функций:

- Смешивание цветов для получения уникальных оттенков с возможностью их сохранения в персональные палитры пользователя.
- Рисование с использованием цветов из созданных палитр.
- Сохранение созданных изображений в различных форматах.
- Импорт изображений для редактирования и применения цветов из палитр.
- Регистрация пользователя.
- Вход и выход из аккаунта.

#### 4.1.2 Исходные данные:

- Для редактирования изображения: исходное изображение, путь к нему, а также разрешение и формат файла.
- Данные пользователя: имя, электронная почта, информация о регистрации.
- Данные о палитрах пользователя, включая названия палитр, список сохраненных оттенков и цветовые коды.
- Статистика ранее пройденных пользователем тестов и опросов.

#### 4.1.3 Результаты:

- Результат пройденного тестирования, включая общее количество правильных и неправильных ответов.
- Созданные оттенки и палитры, с указанием цветовых кодов и названий, присвоенных пользователем.
- Итоги проверки навыков классификации оттенков, включая оценку уровня знаний и областей для улучшения.

### 4.2 Требования к надежности

- Предусмотреть контроль вводимой информации.
- Предусмотреть блокировку некорректных действий пользователя при работе с системой.
- Обеспечить целостность хранимой информации.

### 4.3 Требования к составу и параметрам технических средств

- Система должна работать на IBM совместимых персональных компьютерах и на ноутбуках.
- Минимальная конфигурация:
  - Тип процессора: Intel Core i5 и выше;
  - Операционная система: Windows 10, macOS и выше;
  - Объем оперативного запоминающего устройства: 4 Гб и более.

## 5 Требования к программной документации

5.1. Разрабатываемые программные модули должны быть самодокументированы. Тексты программ должны содержать все необходимые комментарии.

5.2. Программная система должна включать справочную информацию о работе и подсказки пользователю.

5.3. В состав сопровождающей документации должны входить:

- Пояснительная записка, содержащая описание разработки.
- Руководство пользователя.

## 8 Порядок контроля и приемки

- **Тестирование на кроссплатформенность:**
  - Программа успешно скачивается на устройствах Windows и MacOS.
  - Проверить, что программа успешно запускается.
  - Программа корректно исполняет все свои функции на различных системах.

- **Тестирование на надежность:**
  - Проверка на корректность процесса авторизации новых пользователей.
  - Удостовериться, что вход в систему осуществляется без проблем.
  - Проверка на существование логина.
  - Проверка на устойчивость к ошибкам или обработка ошибок с продолжением выполнения программы.

- **Тестирование на безопасность:**
  - Проверка на шифрование пароля.
  - Проверка на недоступность личных данных каждого пользователя другим лицам.

- **Тестирование на функциональность:**
  - Удостовериться, что каждый вопрос викторины доступен в правильной последовательности.
  - Проверка, что картинка, нарисованная пользователем, успешно сохраняется на его устройство.
  - Проверить, что система сохраняет созданные пользователем палитры.
  - Проверка на корректность смешивания цветов.
  - Отображения всех ошибок пользователю, допущенных при ответе на вопросы викторины, а также теоретическое их объяснение.
  - Проверка на наличие всех необходимых для работы программы файлов.
  - Программа позволяет загрузить файл для редактирования в функциональной области «рисование».
  - Программа позволяет сохранить в файл изображение из функциональной области «рисование».
  - Программа позволяет рисовать на пустом холсте.
  - Программа позволяет рисовать на загруженном изображении.

- **Тестирование графического интерфейса:**
  - Проверка на отображения картинок, цветовых схем и вопросов в викторине.

- **Юзабилити-тестирование:**
  - Проверка на удобное расположение кнопок, материала, корректное отображение текста и картинок.
  - Проверить, что пользователь может легко перемещаться между разделами программы.
  - Проверка на интуитивность интерфейса.
